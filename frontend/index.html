Memory Rationale

                    

                        To guarantee high quality, memory scores are dynamically fused using the following weights:
                    

                    
    
                        
  • 50% Vector Similarity: Cosine similarity of schema structure and metadata.
    • 
                        
  • 20% Quality Confidence: Original data quality diagnostic score.
    • 
                        
  • 20% Reuse Count: Log-scaled reuse counts of past findings.
    • 
                        
  • 10% Recency Decay: Time decay (e^-0.05*t) halves relevance in ~14 days.
