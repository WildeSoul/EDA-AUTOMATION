# 📸 Project Portfolio Screenshots Directory

Place the showcase screenshots in this directory. Once added, they will automatically render in the main `README.md` and documentation files on GitHub.

## 📋 Recommended Captures

1. **`home_page.png`**:
   - *Target*: Ingestion page showing the clean Synthetix dark theme, file uploader, the pre-loaded demo buttons, recent session histories list, and the right-hand **Platform Engine Status** card.
2. **`datasets_view.png`**:
   - *Target*: Data intelligence metrics screen showing rows/cols metrics, the color-coded **Data Health Score Gauge**, column data types, and null value distribution charts.
3. **`analysis_labs.png`**:
   - *Target*: The nested tabs under Specialty Labs displaying normality tests, correlation heatmaps, anomaly diagnostics, or baseline ML modeling.
4. **`agent_dag.png`**:
   - *Target*: The **LangGraph Orchestrator (DAG)** tab under Agent System, showing a compiled step execution plan, the human approval gate trigger, and execution timings.
5. **`observability_telemetry.png`**:
   - *Target*: The **Telemetry & Observability** dashboard showing success rates, parallel executor speedups, and memory hit ratios.
6. **`settings_config.png`**:
   - *Target*: The **Settings** page displaying model selection, analysis mode configurations, and active pipeline toggles.

## 🖼️ How to link on GitHub
Once you capture these screenshots, save them as PNGs with the filenames above in this directory (`docs/screenshots/`). The markdown tags:
```markdown
![Home Workspace](docs/screenshots/home_page.png)
```
will automatically display them on your repository page.
